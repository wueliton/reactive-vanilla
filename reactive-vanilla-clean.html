    Small primitives.
    The real DOM.

    Reactive Vanilla is a lightweight reactive JavaScript runtime that works directly on the DOM — a handful of primitives like signals, effects and components, with no JSX, no virtual DOM, no compiler and no build step.

    index.js
    import { signal, effect }
  from "reactive-vanilla";

// a reactive value
const count = signal(0);

// re-runs whenever count changes
effect(() => {
  document
    .querySelector("#counter")
    .textContent = count.value;
});

count.value++; // updates the DOM itself

    // 01 · the problem

    We piled abstraction
    on abstraction

    Somewhere between component thinking and virtual DOM diffing, we forgot that the browser already knows how to update the DOM. A simple form ended up needing three files, a build pipeline, and a framework runtime.

    What we removed

    • JSX
    • Virtual DOM
    • Template compiler
    • Build step

    What is left

    • HTML
    • JavaScript
    • The real DOM
    • Your code

    // 02 · the model

    Six primitives.
    Everything else is you.

    The whole programming model fits on one screen. Combine these primitives into components, and combine components into complete interfaces — no new syntax to learn, just JavaScript and the DOM.

    01

    signals

    Reactive values that notify the moment they change.

    const count = signal(0);
    02

    effects

    Code that automatically re-runs when its signals change.

    effect(() => render(count.value));
    03

    reactive elements

    DOM nodes that stay in sync with your state on their own.

    const view = element(
  () => `<p>${count.value}</p>`
);
    04

    components

    Small functions that own their DOM, state and cleanup.

    function Counter() {
  const n = signal(0);
  return button(n);
}
    05

    contexts

    Share state down a tree without threading props through it.

    const theme = context("dark");
    06

    lifecycle & cleanup

    Dispose effects and listeners exactly when they are done.

    onCleanup(() => store.unsubscribe());

    // 04 · what you can build

    Not a toy library.
    A foundation.

    The minimalist approach is not limited to tiny demos. These are the kinds of interfaces people build with Reactive Vanilla every day.

    Forms

    Validation, binding and submit handling with a handful of primitives — no form library required.

    OTP inputs

    Splitting a code across inputs and wiring paste, autofocus and backspace behavior by hand.

    Drag-and-drop

    HTML5 drag events meet signals, and reorderable interfaces stop being scary.

    Dashboards

    Live panels and charts that update in place as signals fire underneath them.

    Routing

    A URL signal, a couple of effects, and your whole app has routes.

    Custom components

    Grow from a single element into a complete component system without leaving plain HTML.

    // 05 · getting started

    Three steps.
    No build tools.

    Install it, include it, and start writing. Reactive Vanilla works in any environment that speaks HTML, CSS and JavaScript — no configuration, no toolchain.

    01

    Install

    shell
    $npm install reactive-vanilla
    02

    Or drop in a script tag

    index.html
    <script src="https://unpkg.com/
  reactive-vanilla"></script>
    03

    Create your first component

    counter.js
    import {
  signal,
  element,
} from "reactive-vanilla";

const count = signal(0);
const btn = element(() =>
  `<button>${count.value}</button>`
);

btn.on("click", () => count.value++);
document.body.append(btn);

    Maybe you don't need such a large abstraction to build reactive interfaces.

    Explore the documentation, run the examples, or read the source. The whole thing is small enough to understand in one sitting.
